# SaperAi

Сапёр с ИИ, который считает точную вероятность мины в каждой клетке.

[English version](README.md)

В работе. Задумано: классические поля (9×9/10, 16×16/40, 30×16/99, своё), безопасный
первый клик, поле без угадываний, флажки, аккорд, таймер и рекорды; точный решатель,
маленькая сеть на numpy, режимы «ИИ играет сам» и «Подсказка», тепловая карта «Мысли ИИ»,
темы Paint, русский и английский.
