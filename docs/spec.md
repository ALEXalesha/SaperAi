# SaperAi: сапёр с ИИ

Игра из ИИ-Игротеки на Python. Общие правила — `PythonAiGames/docs/contract.md`, очередь — волна 3.

## 1. Игра

- Классический сапёр:
  - новичок 9×9 / 10 мин;
  - любитель 16×16 / 40;
  - профессионал 30×16 / 99;
  - своё поле.
- Первый клик всегда безопасен. Опция: поле без угадываний, которое генератор проверяет решателем.
- Флажки, «аккорд» по цифре (оба клика или средняя кнопка), таймер, рекорды.

## 2. ИИ

1. **Точный решатель.**
   - Граница открытых клеток разбивается на независимые группы.
   - Перебор всех раскладок мин, согласных с цифрами, с учётом общего числа мин.
   - Даёт **точную вероятность мины в каждой клетке**.
   - Сначала простые правила (очевидные мины и безопасные), потом перебор.
   - Для больших границ — ограничение времени и приближение. Это честно отмечается.
2. **Выбор хода при угадывании:** клетка с наименьшим риском, при равенстве — где больше пользы (откроет больше информации или ближе к углу).
3. **Сеть на numpy** — свёрточная, предсказывает вероятность мины по окрестности.
   - Учится на миллионах сгенерированных позиций, цель — точная вероятность от решателя.
   - Сравнение с точным решателем: насколько сеть ошибается и сколько партий выигрывает.
   - Это часть «сеть сама научилась».
- **Уровни:**
  - новичок — только простые правила, угадывает случайно;
  - средний — сеть;
  - сильный — точный решатель.
- **«Мысли ИИ»:** тепловая карта вероятностей поверх поля, числа в процентах.
- **Режим подсказки:** ИИ показывает безопасную клетку или наименее рискованную, если безопасных нет.

## 3. Проверки силы

- Доля выигранных партий на каждом размере, по 10 000 партий с зёрнами.
- Ориентир для сильного на профессионале с безопасным первым кликом — около 50 % и выше. В README пишем настоящую цифру.
- Закон: вероятности точного решателя совпадают с полным перебором на маленьких полях.

## 4. План

1. Каркас по контракту.
2. Правила и генератор, включая «без угадываний».
3. Точный решатель: законы на малых полях, мутационная проверка.
4. Сеть: данные от решателя, обучение, паспорт.
5. Окно: поле, флажки, аккорд, тепловая карта, подсказка, «ИИ играет сам» с выбором скорости.
6. Тесты окна offscreen.
7. Выпуск после «да» Алексея: Gitea, потом свой GitHub (если Алексей его создал) и в составе AiGameRoom.
