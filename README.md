# SaperAi

Minesweeper with an AI that computes the exact mine probability of every cell.

[Русская версия](README.ru.md)

Work in progress. Planned: classic boards (9×9/10, 16×16/40, 30×16/99, custom), a safe
first click, an optional no-guess board, flags, chording, a timer and records; an exact
solver, a small numpy network, "AI plays" and "Hint" modes, an "AI thoughts" heat map,
Paint themes, Russian and English.
